# Basic DNS Typosquatch Checker

## Goals

Build an overview understanding of Go — goroutines, channels, error handling, and basic data structures — while reviewing how DNS works and what the different record types are.

## Spotlights

Concurrent domain scanning using a pipeline pattern: one goroutine distributes jobs across workers, another gathers the results. Channels are buffered to twice the size of the worker pool to avoid congestion and keep the pipeline flowing without unnecessary blocking.


## Lessons Learned

Go's standard library is powerful enough to build network tools without third-party dependencies. Goroutines make concurrent request handling straightforward, and that combination explains why Go is so widely used for web services.
