# ft_nmap

 A basic clone of nmap written in Rust. The goal is to understand how TCP works at the packet level by crafting and sending raw packets using libpnet.

 The scanner performs an ICMP pre-scan to check if the host is up, then scans the requested ports using one of five TCP scan types. Results are displayed with port state, service name, and timing — similar to nmap's output format.

## Goals

 * Understand the TCP three-way handshake
 * Learn how raw sockets work
 * Implement multiple TCP scan techniques (SYN, FIN, XMAS, NULL, ACK)
 * Learn how network interfaces work at a low level in Rust
 * Learn how to use Wireshark to check raw packets

## Spotlights

 For this project, I had to use a low-level library and craft my own packet buffers and send them via raw socket. I used Wireshark to debug what was going on when it was not working as expected. I really enjoy working low-level. I've worked on HTTP servers and this project gave me an understanding of layers 3 and 4 of the OSI model. Wireshark gave me a taste of what the Ethernet protocol looks like.
