# Game Boy Emulator

A Game Boy emulator written in Rust. It emulates the CPU, memory bus, graphics and interrupts well enough to run **Tetris**. Other games did not work.

## Goals

* Learn low-level architecture: registers, opcodes.
* Understand how a CPU works by building a virtual one.
* Get comfortable with Rust on a larger project.

## Spotlights

Implementing interrupts showed me how a game like Tetris is actually written. It is a tiny loop. Most of the logic is written in interrupt. For example, when a VBlanck interrupt is sent by the GPU, the game write the next frame in the graphic memory. At the end of that logic, the code execution come back to the main tiny loop.

## Lessons Learned

* **How a CPU works:** decoding opcodes, flags, the stack and cycle timing, and why every component must stay in sync.
* **Memory management in Rust:** modelling the memory bus and deciding who owns it (CPU, graphics, timers).
* **The borrow checker:** several components need access to the same memory. I had to rethink my design around ownership instead of fighting the compiler, and that made the code cleaner.
